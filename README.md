This single file has 4 dashboards using the O*Net dataset.
O*NET (https://www.onetonline.org/Links to an external site.) is a database of occupation profiles, which are characterized across a variety of axes that include: work task descriptions, competency ratings (e.g. skills, abilities, knowledge and work activities), education requirements, technical skills, related occupations, job families and career clusters. O*NET occupational profile ratings are analytic results of a regularly produced occupational survey that asks employers to evaluate a set of occupations based on work requirements for roles in their business and industry.

O*NET uses three main identifiers to represent occupations within the database:

Occupations (soc_id) use a modified version of Standard Occupational Classification (SOC) system that represent significant occupations present in the US economy.
The SOC identifier allows O*NET to connect with other BLS data, including Occupational Employment and Wage Statistics (OEWS), the annual National Employment Matrix (NEM) ten year projections among others.
O*NET Element identifiers (element_id) use a hierarchical classification scheme that contextually groups related competencies (e.g., skills, knowledge, abilities) and measures and associated ratings across each occupation title in O*NET.
O*NET Scales identifiers (scale_id) are used to identify the evaluative scales used to rate an element (e.g. importance, frequency, or proficiency measures)
Each scale uses a different numeric rating. Some scales also have interpretive anchors that contextualize the numeric values.
O*NET is updated regularly based on surveys of employers and economic analysts. Updates are made to a subset of occupation titles each year, which means that there is variance in the recency of data used across the 1,016 profiles.

O*NET excludes seasonal agricultural occupations. Other occupations are found in O*NET, but are missing all or part of their profiles data. For example, O*NET does not provide profiles for any military occupations. Some occupations are missing knowledge and abilities ratings, because these titles do not require these elements.

More background on the O*NET database can be found on the O*NET Documentation website - https://www.onetcenter.org/
